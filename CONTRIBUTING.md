# Contributing

Thank you for your interest in improving this XSS reference collection!

## How to Contribute

You can help by:

1. Reporting inaccurate, outdated, or incorrectly categorized entries.
2. Proposing additional XSS test cases.
3. Improving descriptions and documentation.
4. Adding browser compatibility notes.
5. Suggesting improvements to the repository structure.

## Guidelines

- Explain what your contribution adds or corrects.
- Include relevant technical context where possible.
- Identify the source of third-party material.
- Do not submit material that you do not have the right to redistribute.
- Avoid including real credentials, private information, or sensitive data.
- Keep contributions relevant to authorized security testing and defensive research.

## Submitting Changes

Open a GitHub Issue to discuss a proposed change, or submit a Pull Request with your contribution.

Thank you for helping improve this resource!
